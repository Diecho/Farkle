# Farkle (C++ Implementation)

A C++ implementation of the dice game Farkle, developed as part of a systems and object-oriented programming project.

## Overview
Farkle is a turn-based dice game where players roll six dice and accumulate points based on scoring combinations. Players can choose to bank points or continue rolling, risking losing their score for the turn.

## Features
- Object-oriented design using multiple classes
- Full implementation of Farkle game rules
- Turn-based gameplay system
- Scoring system based on dice combinations
- Support for weighted dice

## Technologies Used
- C++
- Makefile
- Git & GitHub for version control

## Project Structure
- `die` class: Represents a single die
- `player` class: Manages player state (score, turns)
- `table` class: Controls game state and dice interactions
